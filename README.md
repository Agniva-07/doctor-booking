# Doctor Booking System

This is a React + Vite project for a doctor booking system.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

## Folder Structure

- `src/assets/`: Images, icons, fonts
- `src/components/`: Reusable React components
- `src/layouts/`: Page layouts
- `src/pages/`: Application routes/pages (Home, About, Admin, etc.)
- `src/services/`: API and external service calls
- `src/lib/`: Library configurations (e.g., Supabase)
- `src/hooks/`: Custom React hooks
- `src/utils/`: Utility functions
- `src/styles/`: Global CSS, variables, and responsive styles
